Contact forms built with blocks, right in the editor. Fast, accessible and free, with no upsells.

== Description ==

SwiftForms lets you build forms from blocks in the WordPress block editor. This is a development skeleton: the form blocks arrive in the 1.0.0 release.

== Installation ==

1. Upload the plugin to the `/wp-content/plugins/` folder, or install it from the Plugins screen.
2. Activate it through the Plugins screen.

== Source code ==

The full source, including the JavaScript sources of everything in the `build/` folder, is on GitHub: https://github.com/namithj/swiftforms

To build the plugin from source:

`composer install && npm ci && npm run build`
